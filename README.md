# Задача Коши для системы ОДУ (RK4, Адамс)

## Сборка и запуск
```
  make run
```
Собирает, считает тремя методами и сверяет с точным решением

(гармонический осциллятор: x = cos t, v = -sin t на интервале [0, 2π]).

## Только рассчёт
```
  make
  ./ode_test
```
Результаты:
  rk.dat  — метод Рунге-Кутты 4-го порядка
  ae.dat  — экстраполяционный метод Адамса
  ai.dat  — интерполяционный метод Адамса

## Только сверка результатов
```
  make check
```
Сравнивает rk.dat / ae.dat / ai.dat с точным решением и между собой.

## Очистка
Удалить объектные файлы, .mod и бинарник

```
  make clean       
```
Удалить вместе с файлами rk.dat, ae.dat, ai.dat
```
  make cleanall    
```
